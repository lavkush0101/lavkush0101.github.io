A modern, high-performance portfolio website showcasing **Android Auto (Wired & Wireless)**, **AOSP / AAOS**, **In-Vehicle Infotainment (IVI)**, **HAL / AIDL Middleware**, **SELinux Security Policies**, and **MediaCodec Video Pipelines**.

---

## 🚗 Key Automotive & Framework Highlights

- **Harman International — MSIL (Maruti Suzuki) IVI Platform**: 
  - System-level Diagnostic IVI application with 60+ hardware test features (Factory/Dealer/Eng Mode, CAN SW, RVC Camera, USB port-wise detection).
  - JNI/HAL C++ bindings, custom AIDL system services, and strict SELinux domain isolation (`.te` policies).
- **Harman International — PSA (Peugeot) Android Auto Projection**:
  - Wired (USB Accessory) and Wireless (Wi-Fi Direct 5GHz) projection stack.
  - Low-latency hardware-accelerated MediaCodec H.264/H.265 video decoding directly to Surface (< 20ms).
  - Google PCTS (Projection Compatibility Test Suite) 100% compliance certification.
- **Multimedia & Streaming (Ditty TV / OTT)**:
  - Adaptive bitrate (ABR) ExoPlayer streaming engine with 10-foot Android TV & Fire TV Leanback UI.
- **Enterprise POS (JoyApp POS)**:
  - Inventory management with Zebra hardware barcode scanners and SQLite Room caching.
